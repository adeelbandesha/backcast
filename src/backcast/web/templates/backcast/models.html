Adding a model

Subclass Model in backcast/models.py, return a Forecast with the mean path and its quantiles from 10% to 90%, and add an instance to MODELS. The backtest, leaderboard and charts pick it up. A model that is slow to estimate can implement fit instead, which returns a forecaster that keeps its estimates between refits. 

class Mean(Model):
    key, name, family = "mean", "Historical mean", "Baseline"
    summary = "Forecasts the average price of the whole history."

    def forecast(self, y, h):
        mean = np.full(h, y.mean())
        return Forecast(mean, mean + Z * y.std(ddof=1))  # Z: normal quantiles, one row per forecast quantile
