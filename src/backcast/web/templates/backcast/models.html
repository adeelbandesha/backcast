Adding a model

Subclass Model in backcast/models.py, return a Forecast with the median path and its quantiles from 10% to 90%, and add an instance to MODELS. The backtest, leaderboard and charts pick it up. Every forecast must be a positive price, with the quantiles in increasing order; working on log prices, as the models here do, guarantees both. A model that is slow to estimate can implement fit instead, which returns a forecaster that keeps its estimates between refits. 

class Average(Model):
    key, name, family = "average", "Historical average", "Baseline"
    summary = "Forecasts the average log price of the whole history."

    def forecast(self, y, h):
        log_y = np.log(y)
        median = np.full(h, np.exp(log_y.mean()))
        return Forecast(median, median * np.exp(Z * log_y.std(ddof=1)))  # Z: one row per forecast quantile
