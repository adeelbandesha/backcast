How a backtest works

  1. Walk forward

    The last five years are cut into {{ windows }} back-to-back windows. In each one, every model sees the prices up to a date and forecasts the close 1, 5 or 20 trading days later.

  2. Score only the unseen

    Each forecast is checked against a price the model never saw. Nothing is tuned on the test period, so the error is what you would have got at the time.

  3. Test the margin

    A model that wins on average can still be lucky. A paired t-test on the per-window errors, corrected for trying several models, says whether the gap over naive is larger than chance would produce.
